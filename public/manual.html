00. GENERAL OVERVIEW

A bomb will detonate when its countdown timer reaches 00:00 or when the maximum allowed STRIKES are accumulated. Communication between Expert and Defuser is critical.

  • Serial Number (SN): Check whether the last digit is Odd or Even, and if it contains vowels (A, E, I, O, U).
  • Batteries (BATT): Count total battery cells on side panels.
  • Indicators: Note lit indicators (e.g. lit CAR, lit FRK).

01. WIRES MODULE

Wires are ordered top-to-bottom (Wire 1 to Wire N). Cut only ONE correct wire.

3 Wires

  • If there are no RED wires, cut the 2nd wire.
  • Otherwise, if the last wire is WHITE, cut the last wire.
  • Otherwise, if there is more than one BLUE wire, cut the last blue wire.
  • Otherwise, cut the last wire.

4 Wires

  • If there is more than one RED wire and the last digit of the Serial Number is ODD, cut the last red wire.
  • Otherwise, if the last wire is YELLOW and there are no red wires, cut the 1st wire.
  • Otherwise, if there is exactly one BLUE wire, cut the 1st wire.
  • Otherwise, if there is more than one yellow wire, cut the last wire.
  • Otherwise, cut the 2nd wire.

5 Wires

  • If the last wire is BLACK and the last digit of Serial Number is ODD, cut the 4th wire.
  • Otherwise, if there is exactly one RED wire and more than one yellow wire, cut the 1st wire.
  • Otherwise, if there are no black wires, cut the 2nd wire.
  • Otherwise, cut the 1st wire.

02. THE BUTTON

Follow the initial rules to either TAP (press & quick release < 0.4s) or HOLD the button.

Initial Action:

  1. If button is BLUE and reads "Abort" -> HOLD.
  2. If reads "Detonate" -> TAP.
  3. If there is a lit indicator labeled CAR and batteries >= 2 -> TAP.
  4. If button is WHITE and batteries >= 2 -> TAP.
  5. Otherwise -> HOLD.

If HOLDING the button:

Hold the button down until a colored strip lights up on the right side. Release when the countdown timer has the specified digit in ANY position:

  • BLUE Strip: Release when timer contains 4.
  • WHITE Strip: Release when timer contains 1.
  • YELLOW Strip: Release when timer contains 5.
  • Any Other Color Strip: Release when timer contains 1.
