BOMB DEFUSAL MANUAL

Section 1: Module Defusal Instructions
WARNING: Do not look at the bomb. You are the Expert. The Defuser is alone with the ticking bomb. Provide instructions clearly and calmly.

Bomb Specifications & Indicators (ข้อมูลจำเพาะและไฟแสดงผล)

A bomb casing may feature side indicator labels with a small LED light. Indicators can be either LIT (ไฟติด) or UNLIT (ไฟดับ):

  • CAR: Complete Auto Rubber indicator.
  • FRK: Frequency Radio Keying indicator.
  • SND: Sound Module System indicator.
  • CLR: Clear Ready indicator.

Module 1: Wires (สายไฟ)

A wire module consists of 3 to 5 parallel wires. Only one wire must be cut to safely defuse the module. Wires are counted from top to bottom (1 is the top wire).

3 Wires:

  • If there are no Red wires, cut the second wire.
  • Otherwise, if the last wire is White, cut the last wire.
  • Otherwise, if there is more than one Blue wire, cut the last Blue wire.
  • Otherwise, cut the last wire.

4 Wires:

  • If there is more than one Red wire and the last digit of the Serial Number is ODD, cut the last Red wire.
  • Otherwise, if the last wire is Yellow and there are no Red wires, cut the first wire.
  • Otherwise, if there is exactly one Blue wire, cut the first wire.
  • Otherwise, if there is more than one Yellow wire, cut the last wire.
  • Otherwise, cut the second wire.

5 Wires:

  • If the last wire is Black and the last digit of the Serial Number is ODD, cut the fourth wire.
  • Otherwise, if there is exactly one Red wire and there is more than one Yellow wire, cut the first wire.
  • Otherwise, if there are no Black wires, cut the second wire.
  • Otherwise, cut the first wire.

Module 2: The Button (ปุ่มกด)

See below for instructions on when to TAP or HOLD the button:

  1. If the button is Blue and says "Abort", you must HOLD the button.
  2. Otherwise, if the button says "Detonate", you must TAP the button.
  3. Otherwise, if the button is White and the bomb has 2 or more batteries, you must TAP the button.
  4. Otherwise, you must HOLD the button.

Releasing a Held Button:

When you hold the button down, a colored indicator strip will light up on the right side of the module. Release the button based on the color of this strip:

  • Blue strip: Release when the countdown timer has a "4" in any position.
  • White strip: Release when the countdown timer has a "1" in any position.
  • Yellow strip: Release when the countdown timer has a "5" in any position.
  • Any other strip color: Release when the countdown timer has a "1" in any position.
